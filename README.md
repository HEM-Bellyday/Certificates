## ➕ Adding a New Certificate

1. Upload the PDF into the `certificates/` folder.
2. Open `index.html` and add an entry to the `certificates` list:

```js
{
  title: "Certificate Name",
  meta: "Issuer or topic",
  file: "Your_File_Name.pdf"
}
```

3. Add a row to the table above, then commit. The site updates in about a minute.
